# 已知限制与排查入口

## 功能限制

- 用户没有自助找回密码、支付或充值入口；账户和余额由管理员处理。
- 网页聊天支持文字输入；模型目录取决于用户分组、渠道映射和启用状态。
- 跨协议转换只处理目标协议能表达的字段，详见[协议支持矩阵](protocol-support.md)。
- Desktop 构建产物尚未配置签名、公证和公开 Release；获取方式见[桌面发行](desktop/release.md)。

## 运行与恢复

| 情况 | 处理方式 |
| --- | --- |
| 没有可用模型、调用余额不足 | 按[管理员指南](admin-guide.md)检查授权、映射和正余额 |
| 生成结果不确定 | 先查会话、请求和账单；再次生成可能产生费用 |
| 用量未知或待结算 | 核对请求中的 usage 和价格快照，按[计费策略](billing-cache.md)处理 |
| 有限 RPM 配置超过 4096 | 修正用户或渠道配置；已有值不会自动迁移 |
| 准备回滚到旧 Worker | 核对凭据和表结构；`0029` 删除旧列，`0030` 引入软删除，见[回滚步骤](rollback.md) |

Gate 有限 RPM 的配置上限为 4096；实际容量还受 64 KiB 状态预算、操作 ID 长度和并发请求影响。
