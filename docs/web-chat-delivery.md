# 聊天首页交付记录

2026-09-12；本地实现完成，线上未更新。

## 已实现

- `/` 聊天首页、`/chat/:id` 历史；独立聊天布局、手机侧栏、Markdown 与代码复制。
- 授权分组/模型选择、会话保存/改名/删除、继续聊天、停止、最后一轮重新生成与版本选择。
- 登录草稿保留、用户/路由切换的迟到响应隔离、发送前加锁，以及结果不明确时复用操作 ID 重试。
- 每用户唯一内部 `web_chat` Key，无 Token 或哈希凭据；普通 Key 的鉴权、列表、详情、修改、撤销均排除它。
- 分组精确倍率、基础价格/倍率快照、统一扣费及恢复；普通 API 与聊天共用余额和上游执行链路。
- 请求日志记录来源与实际分组，网页聊天显示为“网页聊天”。

由 8 个 `gpt-5.6-luna`、`max` 子代理分别完成计费、Key、网关、存储、聊天 API、前端、管理 UI、测试，root 负责装配、审查和最终修正。

## 验证结果

- 后端/基础回归：137 个文件、1910 个用例通过。
- 最终局部复验：聊天集成、SSE 故障处理、客户端分帧共 3 文件、14 用例通过。该数字是复验，不与前项重复累加。
- 浏览器：15 个用例按每项最新结果全部通过，覆盖原有注册/管理/九种协议组合，以及新聊天和网络应答丢失重试。
- Worker 与 Vue 类型检查通过，前端生产构建及 Worker 发布 dry-run 通过。
- 桌面与 390px 手机视图已检查，手机文档宽度等于视口 390px，无横向溢出。
- 无真实上游模型调用或真实邮件发送；所有业务数据为隔离本地模拟数据。

关键故障用例包含：虚拟 Key 不能走 Bearer、跨用户/跨组拒绝、旧倍率在途结算、双击只调用一次、应答丢失后同操作重放不再扣费、重新生成不携带旧回答、SSE 分块不重复、保存回调失败仍结束流、取消保存及崩溃遗留状态恢复。

## 审查后修正

- 虚拟 Key 迁移使用原子表替换，保留请求与账务外键；恢复原有账务触发器并检查 FK。
- 最终请求注册校验分组/版本/倍率与价格快照一致，防止错误价目写入请求。
- 同组不同输出上限的渠道使用最高可满足上限，不把所有模型压到最小渠道上限；网关按客户端实际参数筛选渠道。
- 模型目录遵守授权时间，不提前展示未来的访问授权。
- 生成恢复保留短暂收尾窗口，避免 GET 抢先以部分文本完成消息；未关联请求的孤儿记录有界恢复。
- 客户端所有异步结果绑定用户和会话范围；修复重复发送、会话切换、草稿归属及 CRLF 分帧。
- 修正 Vue scoped CSS 中的聊天布局覆盖，避免桌面双侧栏、手机负边距和输入框越界。
