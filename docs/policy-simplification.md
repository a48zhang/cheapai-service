# 接入与校验政策

## 上游接入

- 上游使用 HTTP(S) Base URL 与 API Key，支持 localhost、私网、IPv6、自定义路径和查询参数。
- 上游模型名按输入保存和转发。模型映射指定公开模型、上游名称和协议。
- 供应商扩展请求头透传；渠道凭据构造上游鉴权头，平台凭据和连接管理头留在网关。
- 重定向支持 301/302/303/307/308，最多 20 跳，计入请求超时；跨域移除 Authorization、x-api-key 和 Cookie。
- 同协议扩展字段和 SSE 扩展事件透传；跨协议遇到无法表达的语义时返回转换错误，见[协议支持矩阵](protocol-support.md)。

渠道诊断接受调用方编辑的 JSON，协议必填字段和输出参数由调用方提供。诊断调用可能产生供应商费用。

## 用户与资源

邀请码可不设到期时间，批量数量不设业务上限；已到期、已使用或撤销的邀请码不能注册。Desktop 登录资料交给服务端处理。

模型调用按用户正余额准入，完成后按实际用量结算。用户分组、Key 模型权限、渠道状态和资源归属在服务端校验。

管理写操作使用显式字段、版本冲突检查及审计；注册、授额和扣款使用原子操作与幂等标识。密码使用 Argon2id，认证令牌存摘要，邮件验证码使用 HMAC。

## 运行限制

请求大小、SSE 缓冲、超时、分页、并发租约和 Gate 状态预算约束资源消耗。有限 RPM 接受 1–4096；0/空值表示业务限流关闭，Cloudflare 和供应商限制仍适用。

Desktop 通过受限 IPC 调用 DSH，按账号和服务 generation 隔离会话及凭据。可执行操作集合由宿主定义，供应商返回字段不能直接执行本机命令。
