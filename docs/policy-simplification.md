# 校验与接入政策简化

日期：2026-10-05。对应用户批准的重复校验、防御框架、上游/协议政策、分组上限和非必要 allowlist 清理。本文描述当前工作树，尚未发布；此前的[审计清单](validation-crypto-inventory.md)保留为变更前证据。

## 当前行为

| 范围 | 改动 |
| --- | --- |
| 上游地址 | 接受 HTTP/HTTPS、localhost、私网、IPv6、自定义路径及查询参数；追加协议路径时保留 query。允许其他 CheapAI 实例作为上游。 |
| 请求头 | 供应商扩展头默认透传；Anthropic version/beta 无需预先声明。渠道凭据构造鉴权头，平台凭据和 HTTP 连接管理头不向上游复制。 |
| 重定向 | 支持 301/302/303/307/308，按标准转换 POST/GET，跨域移除 Authorization、x-api-key、Cookie；最多 20 跳，纳入原超时/取消流程。真实 workerd 验证发现原生 follow 会跨域继续发送 x-api-key/Cookie，因此保留局部跳转处理。 |
| 协议能力 | features、reasoningEfforts、cacheTtls 为描述信息，不作能力白名单拦截；nativeExtensions 旧配置被忽略，UI 不再提供编辑器。实际输出预算仍生效。 |
| 扩展参数与流 | 同协议未知请求/响应字段与 SSE 扩展事件透传；跨协议仍对确实不可表达的语义报错。请求解析与能力识别结果由候选复用。 |
| 分组和模型选择 | 移除用户分组、分组渠道关联、API Key 模型选择的 100 项数量限制；实际模型/分组授权关系保留。 |
| 管理审计 | 移除字段筛选框架及 32 项数组、8 KiB 限制。调用方明确构造业务变更，与修改放在同一个 D1 batch；不把原始请求/凭据对象直接写入审计。保留旧列名和响应字段兼容。 |
| 输入与客户端 | 未知普通字段不再导致整个请求/响应失败；数据库写入显式选择业务字段。移除 API client 对表单/controller 已解析提交数据的再次完整解析。 |
| 内部防御 | 移除 JSON 对象的原型/getter/descriptor/Symbol 框架、内部 typed 参数和时钟的重复检查。外部数据解析和业务一致性检查仍在实际边界执行。 |
| 账务指纹 | 简化 JSON 遍历，保持既有有效 JSON 的键排序、数字格式和 SHA-256 输出；保留版本及资源边界。 |
| Desktop | 网络 DTO 接受新增字段；删除已解析凭据/Key/时间的内部复验。保留 IPC 命令授权、进程/账号隔离、系统凭据存储和更新签名。 |

## 必须保留的边界

- 登录、管理员、CSRF、用户与资源归属；Key 的模型权限名单和用户实际获授分组。它们决定谁能读写，不是供应商兼容性政策。
- SQL 显式字段赋值、最后管理员保护、CAS、原子结算/调账、幂等冲突、账务快照版本和 usage 来源。
- 三种已实现协议、实际状态机/终态、无法跨协议表达的 signed/encrypted reasoning 等；后台异步任务尚无完整取回和结算实现，仍不接受 `background:true`。
- HTTP(S) URL 语法、原生 Headers 语法、HTTP 连接管理字段和凭据边界；URL 内嵌 username/password 不受 fetch 支持。
- body/SSE/缓冲区大小、超时、分页、Gate 租约与状态大小、输出预算等运行资源边界。RPM 4096 仍是现有限流实现的边界。
- 密码哈希、Token 用途与哈希、邮件 HMAC、系统凭据 namespace/version、更新签名。
- Desktop IPC/DSH 可执行操作集合、验证过的本机服务地址、generation 隔离；任意供应商字段不会获得执行本机命令的权限。

本轮不改变邀请码批量数量/期限、密码长度等未列入本次执行范围的产品规则。
