# cheapai.dev 桌面使用说明

本分支是开发候选。原生安装、系统密钥链和真实模型链的实际验收范围，以 `evidence/` 报告为准；浏览器预览不能代替桌面宿主。

## 登录与退出

使用 cheapai.dev 邮箱和密码登录，注册与网页控制台入口由宿主打开现有网站。页面不提供 API Key 输入或管理。密码在提交后清空；桌面 Token 由系统凭据库保存，页面只接收用户、余额和登录状态。

桌面 Token 有效期为 90 天。模型调用按需获取本客户端独立 Key；Key 有效期为 30 天，且不超过 Token 到期时间。未到期重启继续使用服务器绑定的同一 Key。自然到期后由服务解析新 Key，不要求人工换 Key，不自动重放失败的模型任务。

退出当前客户端会先向服务器撤销本桌面会话，成功后停止该账号的本地服务并清除本地登录凭据。离线撤销失败会显示未完成，可重新尝试；不会建立后台撤销队列。另一台客户端的会话和 Key 独立。

## 会话与项目目录

登录后选择项目目录，再创建会话。目录选择器取消时不改变当前目录。已有会话绑定原目录，选择另一个目录时创建新会话。会话列表、运行状态、消息与工具执行均由固定版 DSH 提供；切换会话不会自动停止正在执行的任务。

用户与助手消息、代码复制、工具详情和 DSH 等待输入会在对话页显示。发送前可选择可用模型；没有可用模型时不会伪造选项。停止按钮调用 DSH 的取消接口。发送失败保留草稿，重试由用户明确发起。

不同账号使用独立本地 DSH home。退出不会删除历史；同账号重新登录仍使用该账号的历史目录。历史在本机，不承诺云同步。自然登录到期拒绝新的凭据解析，已开始的模型流不被强制中断；登录到期保留草稿引用；账号确认改变后清理旧账号的页面投影。

## 服务、更新与关窗

本地服务故障提供显式重启，不循环自动重启，也不重放任务。普通关窗或菜单退出应用；DSH 报告有运行任务，或其任务基线尚未确认时，宿主提示确认，并先正常停止自有服务，再执行有界终止。

设置页提供账号、通用偏好和手动更新入口。默认目录用于初次工作区，仍由 DSH 创建会话时验证目录；默认模型仅对新会话生效，已有会话保留自己的选择。检查和安装更新是两个动作；未配置可信更新源时显示不可用。未签名开发包不能当作正式公开发行包。项目所需 Git、Python 等工具仍由用户项目环境提供，详见 [运行时分发](runtime-distribution.md)。
