# 用户上手指南

本指南说明 cheapai 的网页聊天、生图、费用、使用记录和 API 接入。

## 1. 登录与注册

打开首页 `/` 后，可从右上角登录。注册入口跟随站点公开注册设置：关闭时登录页隐藏注册链接，直接打开 `/register` 会显示「当前未开放注册」；开放注册填写邮箱和密码，邀请码或邮箱验证码按页面要求填写。新账户初始余额为零，由管理员授额。

登录和注册会保留原返回地址。注册成功后如果页面要求登录，请从登录页继续。当前没有自助找回密码入口，忘记密码请联系管理员。

## 2. 网页聊天

首页 `/` 展示产品介绍、API 接入示例和常见问题。点击「开始对话」进入 `/chat`，已有对话仍可通过 `/chat/:id` 打开。输入消息后发送，回答会逐步显示。未登录时可以先写草稿；点「登录后发送」会转到登录页，登录后回到聊天并恢复草稿，消息不会自动发送。

新对话的输入区位于页面中部。开始对话后，输入区移到底部；输入框随内容增高，长草稿可在框内滚动。桌面端可通过左上角按钮收起或展开侧栏。

发送后，回答位置立即显示等待提示，收到内容后在原位置逐步展开。等待和生成期间可以停止，也可以先编辑下一条草稿，回答结束后再发送。停止、结果确认和连接中断会分别显示对应状态。已经显示的回答和代码可以直接复制；主动发送时会定位到最新一轮，生成途中向上翻看历史则暂停跟随。

模型选择器只显示当前账号可用的模型。若有多个可选项，点击输入框内的模型名称可在模型名称旁打开浮层，按模型名称或授权分组搜索，行末标签以「读 $…/m · 写 $…/m」展示每百万 Token 的输入、输出价格；同名模型会标出分组，价格按该模型在该分组下的实际报价显示。选中模型后浮层自动收起，也可点击外部或按 Esc 关闭。暂无可用模型时，可联系管理员开通权限后点击「刷新」。生成中可停止；最新回答可重新回答，存在多个版本时可切换。侧栏会自动读取聊天记录，滚动到底部继续加载；可在记录行内改名或删除。

网页聊天使用登录身份，不需要 API Key，与 API 调用共用余额。重新回答会再次调用模型并可能产生费用。当前聊天页面支持文字输入，不支持附件上传。

### 图片生成

在侧栏点击「生图」，输入画面描述，选择模型和尺寸，再点击生成按钮。每次生成
一张，发送前会显示单张价格；成功保存后扣费。Enter 换行，Ctrl/⌘+Enter 生成。
生成期间可以编辑下一条描述，结果支持放大预览、下载和复用描述。

生图记录保存在账号下。连接中断时可点击「确认生成结果」，系统会核对原请求，
不会重新生成。暂无可用模型时，请管理员在「生图模型」配置渠道与访问组授权。
当前支持文字生成图片，暂不支持上传参考图或编辑已有图片。

## 3. API 接入

打开顶部「API 接入」或 `/keys`。同一页面显示本站 Base URL、API Key 列表和调用示例。

- Base URL 根据当前站点地址自动生成，通常以 `/v1` 结尾；使用页面显示的地址，避免客户端再次拼接 `/v1`。
- 创建 Key 时填写名称；只有一个可用分组时会自动选中，多个分组会显示各自的模型和价格。
- 新建成功后完整 Key 只显示一次。使用「复制」保存后点「完成」；列表只显示掩码。丢失时撤销旧 Key 并创建新 Key。
- 密钥列表中的「用于接入」会让示例使用所选 Key 实际授权的模型。示例也可按 Chat Completions、Responses 或 Messages 协议切换；复制时页面会附上环境变量设置。

平台 Key 只用于调用本站，不是上游供应商 Key。将 Key 放在本机的安全配置或环境变量中，不要写进公开代码仓库。

## 4. 费用与使用记录

头像菜单中的「费用」打开 `/billing`。页面显示当前余额和所选期间的已结算对话、API 与生图消费，默认期间为浏览器本地时间的本月。修改日期或类型后点击「筛选」；「本月」和「全部时间」直接切换范围。类型和请求编号只筛选明细，期间消费合计包含所选日期内的全部消费。明细金额表示余额变动：扣费为负，授额为正；授额和余额调整不计入消费合计。点击「刷新费用」更新数据。

费用明细可通过「查看记录」进入对应使用记录，或通过「查看图片」打开生图结果；详情中的返回入口会恢复原费用筛选。头像菜单中的「使用记录」打开 `/requests`：列表显示时间、模型、来源、结果和费用；详情页提供请求编号、技术字段以及可展开的 Token 用量和价格快照。来源标为「网页聊天」或「API」。待结算和用量未知的费用需核对后确认。详情中的「相关费用」按请求编号查看全部时间范围的账单。

控制台顶部显示当前位置，账户菜单显示当前邮箱。手机端的密钥、费用和使用记录以卡片展示，状态与操作直接可见；桌面端保留表格。

## 5. 常见问题

| 情况                      | 处理方式                                                                    |
| ------------------------- | --------------------------------------------------------------------------- |
| 暂无可用模型              | 请管理员检查模型、分组和账号授权。                                          |
| 余额不足                  | 打开「费用」查看余额，并联系管理员处理授额。                                |
| API 返回 401              | 检查本站 Key 是否完整、已过期或已撤销；浏览器登录 Cookie 不能代替 API Key。 |
| API 返回 403 或模型不可用 | 检查所选 Key 的授权分组和可用模型，必要时联系管理员。                       |
| 费用未知或待结算          | 到对应使用记录查看执行和结算状态；不要把未知金额当成零。                    |
| 收不到邮箱验证码          | 检查邮箱和页面提示；持续失败时联系管理员确认邮件服务。                      |

对外反馈报错时，请提供发生时间、页面和请求编号。不要发送密码、验证码或完整 API Key。
