# 用户上手指南

本指南说明 React 版 cheapai 的网页聊天、费用、使用记录和 API 接入。页面更新情况以站点当前部署版本为准。

## 1. 登录与注册

打开首页 `/` 后，可从右上角登录。注册入口跟随站点公开注册设置：关闭时登录页隐藏注册链接，直接打开 `/register` 会显示“当前未开放注册”；开放注册填写邮箱和密码，邀请码或邮箱验证码按页面要求填写。新账户初始余额为零，由管理员授额。

登录和注册会保留原返回地址。注册成功后如果页面要求登录，请从登录页继续。当前没有自助找回密码入口，忘记密码请联系管理员。

## 2. 网页聊天

首页直接进入聊天。输入消息后发送，回答会逐步显示。未登录时可以先写草稿；点“登录后发送”会转到登录页，登录后回到聊天并恢复草稿，消息不会自动发送。

模型选择器只显示当前账号可用的模型。若有多个可选项，可按模型和授权分组选择；同名模型会标出分组，价格按该模型在该分组下的实际报价显示。生成中可停止；最新回答可重新回答，存在多个版本时可切换。侧栏会自动读取聊天记录，滚动到底部继续加载；可在记录行内改名或删除。

网页聊天使用登录身份，不需要 API Key，与 API 调用共用余额。重新回答会再次调用模型并可能产生费用。当前聊天页面支持文字输入，不支持附件上传。

## 3. API 接入

打开顶部“API 接入”或 `/keys`。同一页面显示本站 Base URL、API Key 列表和调用示例。

- Base URL 根据当前站点地址自动生成，通常以 `/v1` 结尾；使用页面显示的地址，避免客户端再次拼接 `/v1`。
- 创建 Key 时填写名称；只有一个可用分组时会自动选中，多个分组会显示各自的模型和价格。
- 新建成功后完整 Key 只显示一次。使用“复制”保存后点“完成”；列表只显示掩码。丢失时撤销旧 Key 并创建新 Key。
- 表格中的“用于示例”会让示例使用所选 Key 实际授权的模型。示例也可按 Chat Completions、Responses 或 Messages 协议切换；复制时页面会附上环境变量设置。

平台 Key 只用于调用本站，不是上游供应商 Key。将 Key 放在本机的安全配置或环境变量中，不要写进公开代码仓库。

## 4. 费用与使用记录

头像菜单中的“费用”打开 `/billing`。页面显示实时余额和所选期间的已结算模型消费，默认期间为浏览器本地时间的本月。日期或类型变更后立即生效；类型只筛选明细，不改变期间消费合计。管理员授额和余额调整仍显示在明细中，但不计入消费合计。旧 `/dashboard` 链接会跳转到费用页。

费用明细可通过“查看记录”进入对应使用记录。头像菜单中的“使用记录”打开 `/requests`：列表显示时间、模型、来源、结果和费用；详情页提供请求编号、技术字段以及可展开的 Token 用量和价格快照。来源标为“网页聊天”或“API”。待结算、用量未知等状态会用文字呈现，不代表零费用。

## 5. 常见问题

| 情况                      | 处理方式                                                                    |
| ------------------------- | --------------------------------------------------------------------------- |
| 暂无可用模型              | 请管理员检查模型、分组和账号授权。                                          |
| 余额不足                  | 打开“费用”查看余额，并联系管理员处理授额。                                  |
| API 返回 401              | 检查本站 Key 是否完整、已过期或已撤销；浏览器登录 Cookie 不能代替 API Key。 |
| API 返回 403 或模型不可用 | 检查所选 Key 的授权分组和可用模型，必要时联系管理员。                       |
| 费用未知或待结算          | 到对应使用记录查看执行和结算状态；不要把未知金额当成零。                    |
| 收不到邮箱验证码          | 检查邮箱和页面提示；持续失败时联系管理员确认邮件服务。                      |

对外反馈报错时，请提供发生时间、页面和请求编号。不要发送密码、验证码或完整 API Key。
