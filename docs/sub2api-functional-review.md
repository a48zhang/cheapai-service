## 下一步顺序

1. 优先完成真正的异步任务提交和查询，定义断线、超时、取消及结算行为；再允许后台并行生成。
2. 基于现有所有者权限补历史搜索、删除和保存策略；删除不能丢失已发生的账目。
3. 按实际渠道支持扩展 API 图片入口、参考图和批量输出，按尺寸/画质报价；避免先堆表单再补计费。
4. 控制台补可搜索模型筛选、跨页导出、汇总接口，再做趋势与概览。

本轮保留聊天的即时助手反馈、滚动控制和停止/恢复语义，它们直接对应发送后无响应的问题。
不会为了减少代码删除鉴权与防重复扣费，也不会把上述尚未支持的能力包装成已完成。
验证使用模拟供应商和本地 Worker，真实付费渠道仍需联调。
